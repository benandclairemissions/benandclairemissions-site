HOW TO EDIT YOUR SITE (no AI needed)

FILES
  index.html   All words and sections, top to bottom.
  style.css    Colors, fonts, spacing (the top block).
  settings.js  Your links: booking, contact form, giving, email, video.
  photo1.jpg, photo2.jpg   Story photos (add yourself).
  work1.jpg ... work6.jpg  Tentmaking gallery images (add yourself).

COMMON CHANGES
  Words:           index.html, edit text between > and <. [Brackets] are placeholders.
  Colors / fonts:  top of style.css. Fonts: pick one at fonts.google.com, then change
                   the font name in style.css AND the fonts <link> line in index.html.
  Add a gallery project / music card: copy one whole line, paste it under the last, edit it.
  Remove a project/section: delete the whole line / the whole <section> ... </section>.
  Reorder sections: cut and paste a whole <section> block above or below another.
  Gallery columns: in style.css change --cols. Page width: --maxw. Section spacing: --pad.
  Swap a section's look: on the <section> tag, add or remove class="light" (light background).

PUBLISHING
  github.com -> your repo -> click a file -> pencil icon -> edit -> Commit changes.
  To add photos: Add file -> Upload files -> Commit. Your live site updates in 1-2 minutes.
  Every older version is kept in the file's History if you need to undo.
